═══════════════════════════════════════════════════════
🎯 LOYIHA MAQSADI
═══════════════════════════════════════════════════════
Tibbiyot talabalari (1-6 kurs) test savollari orqali imtihonga tayyorlanadi. 
Ular YAKKA (solo) yoki GURUH (multiplayer) rejimida test yechishadi. 
Kim ko'proq to'g'ri javob bersa — shu ball va reyting oladi. 
Gamifikatsiya tizimi orqali rag'batlantiriladi.

═══════════════════════════════════════════════════════
⚙️ TEXNOLOGIYALAR (qat'iy)
═══════════════════════════════════════════════════════
- Framework: Remix (React) — file-based routing
- Styling: TailwindCSS
- Font: Poppins (Google Fonts, 400/500/600/700 weight)
- Icons: remixicon (https://remixicon.com) — <i className="ri-xxx-line" /> 
  formatida ishlatiladi, CDN yoki npm orqali import qilinadi
- State: React hooks + Context (savatcha, timer, user)
- Mock data: local JSON fayllar (backend hozircha yo'q)
- TypeScript majburiy

✨ ASOSIY XUSUSIYATLAR
═══════════════════════════════════════════════════════

1) 🏠 DASHBOARD
   - Salomlashish: "Salom, [Ism] 👋"
   - Umumiy statistika kartalari:
     • Yechilgan testlar soni
     • O'rtacha ball (%)
     • Joriy streak (ketma-ket kunlar)
     • Umumiy XP / Level
   - "Davom etish" tugmasi (oxirgi fan)
   - Kunlik challenge widget
   - Top 3 foydalanuvchi mini-reyting

2) 📚 FANLAR (subjects)
   Tibbiyot fanlari: Anatomiya, Fiziologiya, Biokimyo, Patologiya, 
   Farmakologiya, Mikrobiologiya, Ichki kasalliklar, Xirurgiya, Pediatriya, 
   Ginekologiya...
   - Har bir fan kartasi: ikonka, nom, savollar soni, progress %
   - Bosilganda test boshlanadi

3) ✍️ YAKKA TEST (solo quiz)
   - Har savol uchun 30 soniya timer (doiraviy progress)
   - 4 variantli (A/B/C/D) savollar
   - Javob tanlanganda: yashil (to'g'ri) / qizil (noto'g'ri) animatsiya
   - "Keyingi" tugmasi
   - Savol raqami: "12/50"
   - Chalg'ituvchi (flag) tugmasi
   - Oxirida: natija ekrani
     • To'g'ri javoblar %
     • XP qo'shilishi
     • Xato savollar tahlili
     • "Qayta urinish" / "Reytingga qaytish"

4) ⚔️ GURUH BATTLE (multiplayer)
   LOBBY:
   - Xona kodi generatsiya qilish (6 xonali)
   - Kod orqali qo'shilish input
   - Do'stlarni taklif qilish (link copy)
   - O'yinchi ro'yxati (avatar + ism)
   - Sozlamalar: savollar soni (10/20/30), vaqt (15/30/60s), fan tanlash
   - "Boshlash" tugmasi (host)

   BATTLE EKRANI:
   - Har o'yinchi uchun real-time progress bar
   - Har bir savolda kim birinchi to'g'ri topsa — ko'proq ball
   - Live reyting (yon panelda)
   - Chat (emoji reactions)
   - Oxirida: g'olib animatsiyasi 🏆 (confetti)

5) 🏆 GAMIFIKATSIYA
   - XP tizimi: to'g'ri javob = +10 XP, tez javob = +5 bonus
   - Level: har 500 XP da yangi daraja
   - Streak: ketma-ket kunlar uchun bonus
   - Badge/Yutuqlar:
     • "Birinchi qadam" — 1-test
     • "Anatomiya ustasi" — 100% Anatomiya
     • "Speedster" — 10s ichida 10 to'g'ri javob
     • "Champion" — 1-o'rin battle'da
     • "Marafon" — 30 kun streak
   - Leaderboard: Kunlik / Haftalik / Umumiy

6) 👤 PROFIL
   - Avatar (rasm yuklash yoki emoji)
   - Universitet, kurs, fakultet
   - Statistika grafigi (kunlik/haftalik)
   - Yutuqlar galereyasi
   - Sozlamalar
